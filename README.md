# Heart Disease Prediction using Machine Learning

A machine learning classification project that analyzes the UCI Heart Disease dataset and compares two models: **Logistic Regression** and **Decision Tree Classifier**.

## Project Overview

The notebook (`Week4projectheart_diseas.ipynb`) walks through data loading, exploration, cleaning, preprocessing, model training, evaluation, visualization, and saving trained models.

The target is created from the dataset's `num` column:

- `0` — No Heart Disease (`num == 0`)
- `1` — Heart Disease (`num > 0`)

## Models Used

1. **Logistic Regression** — trained with `max_iter=2000` and balanced class weights.
2. **Decision Tree Classifier** — trained with `max_depth=5`, `min_samples_leaf=5`, and balanced class weights.

Both models use preprocessing pipelines:

- Numerical features: median imputation and standard scaling.
- Categorical features: most-frequent imputation and one-hot encoding.

## Workflow

1. Import Python libraries.
2. Load the `heart_disease_uci.csv` dataset.
3. Explore dataset information, descriptive statistics, and missing values.
4. Remove duplicate rows.
5. Create a binary target column.
6. Separate features and target; exclude `id`, `dataset`, and `num` from the features.
7. Split data into training and testing sets (80/20), using stratification and `random_state=42`.
8. Build preprocessing pipelines and train both classifiers.
9. Generate predictions and compare Accuracy, Precision, Recall, and ROC-AUC.
10. Plot confusion matrices, ROC curves, model comparison, and feature importance.
11. Save the trained models and model comparison results.

## Evaluation Metrics

- **Accuracy:** Overall proportion of correct predictions.
- **Precision:** Proportion of predicted positive cases that are positive.
- **Recall:** Proportion of actual positive cases correctly identified.
- **ROC-AUC:** Measures how well the model separates the two classes across thresholds.
- **Confusion Matrix:** Shows true/false positive and negative predictions.

The notebook prints the metric values after training. Results depend on the dataset file and execution environment.
